How it works

This is a clickable prototype using fictional student messages and rule-based routing. Filters, message details, and demo reply status run locally in your browser. They do not access email, financial aid accounts, or Temple systems.

The Jotform chatbot is embedded separately for the student experience. It is not connected to this staff inbox.
